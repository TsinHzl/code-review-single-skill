## code-review-single

Single-repo Code Review Expert. Extracts the current branch diff via Git, performs deep review of logic bugs, boundary gaps, readability, performance, and security issues.

### Features

- **Four diff modes** — commit hash, time range, commit count, or source branch comparison (priority: hash > time > count > source)
- **Time range support** — "today", "last 3 days", "last week", "last 2 hours" etc.
- **Component path scoping** — `@src/auth/` to limit review to a subdirectory
- **Deep review** — 6-dimension scan (security, crash/exception, logic errors, performance, code style, refactoring)
- **Structured Markdown report** — written to file via `references/report-template.md`

### Usage

```
/code-review-single                    # Source branch (default)
/code-review-single abc1234            # Commit hash → HEAD
/code-review-single today              # Today's commits
/code-review-single last 3 days        # Last 3 days
/code-review-single @src/auth/         # Scoped to component
```

### Output

```
<working-directory>/<TARGET_COMPONENT>-code-review.md
```

## code-review-multi

Batch multi-repo Code Review Expert. Auto-scans all `.git` subdirectories under the current working directory, performs deep review on each, and generates a unified report.

### Features

- **Auto-discovery** — scans all Git repos under current directory
- **Batch processing** — reviews each repo independently
- **Unified report** — all repos in a single Markdown file
- **Smart skip** — repos with no changes are silently excluded from the body

### Usage

```
/code-review-multi
batch review all repos
```

### Output

```
<root-directory>/<ROOT_DIRECTORY_NAME>_code_review.md
```

## code-review-single（单仓库 Code Review 专家）

### 功能

- **四种 diff 模式** — commit hash、时间范围、commit 数量、源分支对比（优先级：hash > 时间 > 数量 > 源分支）
- **时间范围支持** — "今天内"、"最近三天"、"最近一周"、"最近两小时"等
- **组件路径限定** — `@src/auth/` 限定审查子目录
- **六维深度扫描** — 安全漏洞、崩溃与异常、逻辑错误、性能问题、代码规范、重构机会
- **结构化报告** — 通过 `references/report-template.md` 模板输出

### 使用方式

```
/code-review-single                    # 源分支（默认）
/code-review-single abc1234            # 指定 commit → HEAD
/code-review-single 今天内             # 今天的提交
/code-review-single 最近三天           # 最近 3 天
/code-review-single @src/auth/         # 限定组件路径
```

### 输出路径

```
<工作目录>/<TARGET_COMPONENT>-code-review.md
```

---

## code-review-multi（批量多仓库 Code Review 专家）

### 功能

- **自动发现** — 扫描当前目录下所有 `.git` 子目录
- **批量处理** — 独立审查每个仓库
- **统一报告** — 所有仓库汇总至单个 Markdown 文件
- **智能跳过** — 无改动仓库不出现在正文中

### 使用方式

```
/code-review-multi
批量 review 所有仓库
```

### 输出路径

```
<根目录>/<ROOT_DIRECTORY_NAME>_code_review.md
```
